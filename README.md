**Program pro počítání třetí mocniny a odmocniny.**

Zadáte číslo pro výpočet třetí mocniny; program zkontroluje, zda je vstup vhodný pro výpočet. Když ne, požádá o zadání čísla ještě jednou. Jakmile dostane vhodné číslo, vypočítá a vypíše výsledek.

Pak zadáte číslo pro výpočet odmocniny; program zkontroluje, zda je vstup vhodný pro výpočet. Když ne, požádá o zadání čísla ještě jednou. Jakmile dostane vhodné číslo, vypočítá a vypíše výsledek.

**Program for calculating cube and square root.**

You enter a number to calculate the cube; the program will check whether the input is suitable for calculation. If not, it will ask you to enter the number again. Once it gets a valid number, it will calculate and display the result.

Then you enter a number to calculate the square root; the program will check whether the input is suitable for calculation. If not, it will ask you to enter the number again. Once it gets a valid number, it will calculate and display the result.
